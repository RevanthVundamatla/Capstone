How the agent works

State

Each degraded UIEB image is represented by an observation that the policy uses to decide how to enhance it.

Action

DDPG outputs a continuous correction vector controlling red, green and blue gains, gamma, contrast, saturation and local-contrast strength.

Reward

The environment scores the corrected image using the implemented quality metrics and color-cast measurement. The reward guides learning.

Policy

An actor-critic pair learns a correction policy over training episodes. Validation results help identify a promising checkpoint.

Why these four metrics

The project tracks reference-based fidelity and no-reference underwater image quality.

PSNR
Pixel-level fidelity to a reference image, measured in decibels. Higher values generally indicate lower pixel error.
SSIM
Structural similarity to a reference image, considering luminance, contrast and structure.
UIQM
Underwater Image Quality Measure, a no-reference measure combining colorfulness, sharpness and contrast.
UCIQE
Underwater Color Image Quality Evaluation, a no-reference measure based on underwater color and luminance characteristics.
